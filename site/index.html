Set up

Operating system

  1. Download and unzip, or clone.

    git clone https://github.com/jthy10/nopostnow.git

  2. Run the launcher in that folder.

    sh nopostnow.sh.\nopostnow.cmd

  3. Answer the questions in the panel that opens, then sign in at localhost:3000.

  4. Put it online with a domain and a Cloudflare Tunnel, then send invite links. Guide

Commands

Startsh nopostnow.sh.\nopostnow.cmd
Start without the panelsh nopostnow.sh.\nopostnow.cmd start
Change settingssh nopostnow.sh.\nopostnow.cmd setup
Make an invite linksh nopostnow.sh.\nopostnow.cmd users invite
Reset a passwordsh nopostnow.sh.\nopostnow.cmd users reset their@email
Make someone an adminsh nopostnow.sh.\nopostnow.cmd users admin their@email
Updategit pull, then start again
